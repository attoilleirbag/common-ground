# Common Ground

Small, free, browser-only tools for sharing life with other people.

| Tool | What it does |
|---|---|
| [Tally](tally/) | Splits shared expenses and finds the fewest payments that settle everyone up |
| [Overlap](overlap/) | Lines up working hours across cities for a chosen date, with daylight saving handled |
| [Handover](handover/) | Room-by-room rental condition report with dated photos, meter readings and keys, saved as a PDF |

Each tool is one HTML file with no build step and no server. Data stays in the visitor's browser: Tally and Overlap use localStorage, Handover uses IndexedDB so photos fit.

Companion project: [Border Kit](https://github.com/attoilleirbag/border-kit).
